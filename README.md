# Shtëpia e Ëndrrave 2024

Shtëpi 3D e ndërtuar tërësisht me CSS art — lëviz miun mbi skenë për ta rrotulluar.

## Si ta hapësh

Hap `index.html` në browser për faqen prezantuese (Live Demo + Kodi Burim),
ose `demo/index.html` direkt për demo-n live.

## Struktura

- `index.html` — faqja showcase (demo + kodi burim)
- `demo/` — demoja web që funksionon
- `original/` — file-t origjinale të paprekura
